隐私政策

适用产品：阅微 - 网页读薄器（Chrome / Microsoft Edge 扩展程序）
最后更新：2026 年 10 月 19 日 · 生效日期：2026 年 10 月 19 日
一句话总结：阅微没有自己的服务器。我们不收集、不上传、不存储你的任何数据。 你阅读的网页正文会从你的浏览器直接发送到你自己选择的 AI 服务商，用的是你自己的 API Key。 除此之外，没有任何人（包括我们）能看到你读了什么。

一、我们是谁

阅微（下称"本扩展"）是一款浏览器扩展程序，可运行于 Google Chrome 及 Microsoft Edge （两者均基于 Chromium 内核，同一份扩展包同时支持），用于把网页文章提炼成简短摘要与要点。 本政策的发布者是本扩展的开发者（下称"我们"）。 如有任何隐私相关问题，可通过文末的联系方式与我们联系。

二、本扩展处理哪些数据

2.1 网页内容（仅在您主动点击时）

当您点击"30 秒读完"按钮时，本扩展会读取当前标签页的正文内容（包括标题、正文文本、网址、网站域名）。 这通过 Chromium 扩展的 activeTab 权限实现——该权限只在你主动点击扩展图标后才对这个标签页生效， 本扩展无法在你没有操作时读取任何网页。

读取到的正文会直接从你的浏览器发送给你所选择的 AI 服务商（见第 3 节），用于生成摘要。 我们不会收到、也不会留存这份内容。

2.2 API Key

你需要自行填写一个 AI 服务商的 API Key 才能使用本扩展。该 Key：

  • 存储在你本机的浏览器存储（chrome.storage.local）中；
  • 不会同步到你的浏览器账号（Microsoft 账号或 Google 账号），不会上传到任何服务器，我们也无法获取；
  • 仅用于向对应服务商的 API 发起请求，作为身份凭证。

2.3 偏好设置

模型供应商、模型名称、笔记风格等设置项，保存在 chrome.storage.sync 中， 以便在你登录同一浏览器账号（Microsoft 账号或 Google 账号）的多个设备间同步。这类数据不包含 API Key，也不包含任何网页内容。

2.4 收藏记录

当你使用"收藏到收藏墙"功能时，该文章的标题、网址、摘要与收藏时间会保存在 你本机的浏览器存储（chrome.storage.local）中，用于在"收藏墙"页面展示。 这些数据不会上传，也不会跨设备同步。

2.5 我们不收集的数据

本扩展明确不收集以下任何信息：

  • 你的姓名、电子邮箱、电话号码或任何账号信息
  • 你的浏览历史、书签、Cookie、密码或表单内容
  • 你的地理位置、IP 地址或设备标识符
  • 键盘输入、鼠标行为或其他使用行为埋点
  • 任何用于广告投放或用户画像的标识符

三、数据会发送到哪里

本扩展本身没有后端服务器。当你点击提炼时，网页正文会从你的浏览器 直接发送到你在设置中选择的 AI 服务商。我们对这些请求没有任何中转、记录或访问能力。

请注意：这些第三方服务商如何存储、使用你发送的内容，由它们各自的隐私政策约束，我们无法控制。 如果你阅读的是敏感内容，建议先确认所选服务商的数据处理条款，或选择你信任的服务商。

四、数据共享与出售

我们不出售你的任何数据，不将数据用于广告、用户画像或信用评估， 不向任何第三方转让数据（唯一的第三方传输即第 3 节所述的、由你主动触发并由你选择服务商的 AI 接口）。

五、数据保留与删除

  • 自动删除：清理浏览器扩展数据、卸载本扩展，即可删除本扩展存储的全部内容。
  • 手动删除：收藏墙页面提供单条删除与"清空"按钮；设置页可随时清空 API Key。
  • 服务器端：由于我们没有服务器，不存在需要申请删除的服务端数据。

六、数据安全

  • 所有网络请求均通过 HTTPS 加密传输。
  • API Key 仅存储于本机，不跨设备同步，降低凭证泄露风险。
  • 本扩展不加载、不执行任何远程代码，所有逻辑随扩展包一同分发。
  • 扩展申请的是 Chromium 扩展体系的最小必要权限，未申请读取全部网站（<all_urls>）、 Cookie、历史记录等高敏权限。

七、儿童隐私

本扩展不面向 13 岁以下儿童，也不会主动收集儿童的任何个人信息。

八、符合应用商店"有限使用"要求

本扩展对用户数据的处理符合 Chrome 应用商店用户数据政策及 Microsoft Edge 加载项商店 相关开发者政策中的"有限使用"（Limited Use）要求，具体包括：

  • 仅在实现扩展单一用途（网页内容提炼）所必需时传输数据；
  • 不将数据传输用于广告、个性化推荐或任何与单一用途无关的目的；
  • 不将数据用于判断信用等级或用于放贷；
  • 不向第三方出售数据；
  • 除法律要求外，不向任何第三方披露数据——且本扩展本身不持有可披露的数据。

九、政策变更

若本政策发生实质性变更，我们会在本页面更新"最后更新"日期，并在扩展的更新说明中提示。 继续使用本扩展即视为接受更新后的政策。

十、联系我们

对本政策有任何疑问，或希望行使数据相关权利，请通过以下方式联系：

Privacy Policy

Product: Yuewei — Read Less, Know More (Chrome / Microsoft Edge Extension)
Last updated: October 19, 2026
In one sentence: Yuewei has no backend server. We do not collect, upload, or store any of your data. Article text is sent directly from your browser to the AI provider you chose, using your API key.

1. What This Extension Processes

1.1 Web page content (only when you click)

When you click the "Read in 30s" button, the extension reads the main text of the current tab (title, body text, URL, and domain). This uses the Chromium activeTab permission, which only applies to a tab after you explicitly click the extension icon. The extension cannot read any page without your action.

The extracted text is sent directly from your browser to the AI provider you selected, in order to generate a summary. We never receive or retain this content.

1.2 API key

  • Stored locally in chrome.storage.local on your device;
  • Not synced to your browser account (Microsoft or Google), not uploaded anywhere, and inaccessible to us;
  • Used solely as the credential for requests to your chosen provider.

1.3 Preferences

Provider, model, and note-style settings are stored in chrome.storage.sync so they can follow your browser account (Microsoft or Google) across devices. These contain no API key and no page content.

1.4 Saved articles

When you use "Save to Library", the article's title, URL, summary, and save time are stored locally in chrome.storage.local for display on the Library page. This data is never uploaded or synced.

1.5 What we do NOT collect

We do not collect your name, email, phone number, account information, browsing history, bookmarks, cookies, passwords, form data, location, IP address, device identifiers, keystrokes, or behavioral analytics. We use no advertising or user-profiling identifiers.

2. Where Data Is Sent

This extension has no backend server. When you trigger a summary, the article text is sent directly from your browser to the AI provider selected in settings. We cannot intercept, log, or access these requests.

Supported providers and their privacy policies: Zhipu AI (default, free), DeepSeek, Alibaba Cloud DashScope (Qwen), and OpenAI. Links are provided in the Chinese section above.

Note: How these third parties store and use your content is governed by their own privacy policies and is outside our control. If you are reading sensitive material, please review the provider's terms first.

3. Data Sharing and Sale

We do not sell your data, do not use it for advertising, profiling, or credit assessment, and do not transfer it to any third party other than the AI endpoint you deliberately invoke.

4. Data Retention and Deletion

  • Automatic: Clearing extension data or uninstalling the extension deletes everything it stored.
  • Manual: The Library page offers per-item delete and a "Clear all" button; the settings page lets you clear your API key at any time.
  • Server-side: Since we operate no servers, there is no server-side data to request deletion of.

5. Security

  • All network requests use HTTPS.
  • API keys are stored locally only and are not synced across devices.
  • The extension loads and executes no remote code; all logic ships with the package.
  • Only minimum necessary Chromium extension permissions are requested — no <all_urls>, cookies, or history access.

6. Children's Privacy

This extension is not directed to children under 13 and does not knowingly collect their personal information.

7. Store Limited Use Compliance

Our handling of user data complies with the Chrome Web Store User Data Policy and the Microsoft Edge Add-ons developer policies, including the Limited Use requirements: data is transferred only as necessary for the extension's single purpose; it is not used for advertising, personalization, or creditworthiness; it is not sold; and it is not disclosed to third parties except as required by law — and the extension itself holds no data to disclose.

8. Changes

If this policy changes materially, we will update the "Last updated" date above and note it in the extension's release notes. Continued use constitutes acceptance of the updated policy.

9. Contact

For any questions about this policy: wangliran@live.cn
